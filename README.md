# ParkShare - FIS

Proyecto desarrollado para la asignatura **Fundamentos de Ingeniería del Software (FIS)** de la Universidad de La Laguna.

El objetivo de la práctica es desarrollar una aplicación llamada **ParkShare**, centrada en la gestión y compartición de plazas de aparcamiento entre usuarios.

---

# Descripción del proyecto

ParkShare es una aplicación orientada a la gestión de aparcamientos compartidos.  
El proyecto está estructurado siguiendo una organización modular basada en clases y separación de responsabilidades.

El sistema desarrollado, denominado ParkShare, tiene como objetivo facilitar el alquiler temporal de plazas de aparcamiento entre particulares y comunidades de vecinos, permitiendo conectar a propietarios de plazas disponibles con usuarios que necesitan estacionamiento de forma rápida, segura y organizada.

# Estructura del proyecto

| Ruta | Descripción |
|---|---|
| `FIS/` | Código fuente principal del proyecto |
| `include/` | Archivos de cabecera (`.h` / `.hpp`) |
| `models/` | Modelos y representación de entidades |
| `controllers/` | Control de la lógica de la aplicación |
| `views/` | Gestión de vistas e interacción |
| `utils/` | Funciones auxiliares y utilidades |
| `main.cpp` | Punto de entrada de la aplicación |
